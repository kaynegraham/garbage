## kaynes_garbage 🗑️
Simple garbage script created for QBox with ox_lib

Extremely configurable, integrated with qbx_vehiclekeys and ox_fuel to ensure a streamlined experience. 
- Supports: QBox
- Requires: [ox_lib)[https://github.com/overextended/ox_lib/releases/tag/v3.24.0]

Features:
- Extremely configurable and easy to install
- Outfit changing and configuration
- Multiple props and locations available
- Runs at a very low latency
